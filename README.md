# 🦁 Little Explorers – ABC Zoo Trail

> **Tap a letter, meet its friend, and hear it out loud! 🐾**

**Little Explorers – ABC Zoo Trail** is an interactive and kid-friendly alphabet learning web application designed to make learning A–Z more fun and engaging.

Instead of simply displaying letters, the app turns every alphabet into a little adventure where children can explore letters, discover their associated words, view colorful images, and listen to their pronunciation.

## ✨ Features

* 🔤 Explore all **26 English alphabets**
* 🐾 Animal-themed learning experience
* 🖼️ Display a related image for each letter
* 🔊 Play audio pronunciation
* ⌨️ Type a letter and press Enter
* 🖱️ Tap any alphabet to explore
* 📊 Track learning progress from **0 / 26**
* 🔄 Move through letters and continue the trail
* ✨ Interactive animations and child-friendly UI
* 📱 Responsive design for different screen sizes

## 🎯 Learning Flow

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Make sure the image and audio files are present.
4. Open `index.html` in a browser.
5. Start exploring the alphabet! 🎉
